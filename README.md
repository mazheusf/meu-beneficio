# Meu Benefício — VR + VA

Aplicativo pessoal para acompanhar saldo, despesas e créditos de vale-refeição (VR) e vale-alimentação (VA).

## Publicação gratuita com GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**.
4. Salve e aguarde a publicação.
5. O endereço ficará no formato `https://mazheusf.github.io/meu-beneficio/`.

## Privacidade e dados

- Os saldos e lançamentos são armazenados no `localStorage` do navegador.
- Nenhum dado financeiro é enviado ao GitHub ou a um banco de dados.
- O repositório contém apenas o código público do aplicativo.
- Use **Ajustes → Exportar backup** regularmente. Limpar os dados do Safari pode apagar os lançamentos locais.

## Valores iniciais

- Saldo inicial: R$ 1.223,50 em VR e R$ 1.223,50 em VA.
- Crédito mensal: R$ 1.227,16 em VR e R$ 967,00 em VA.
- O crédito mensal é lançado manualmente, mediante confirmação, para evitar duplicidade.
